# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website designed to showcase my skills, education, and machine learning/data science projects.

## Features
- **Responsive Layout:** Smooth viewing experience across desktop and mobile devices.
- **Interactive Modals:** Dynamic modal popups to view detailed project descriptions and preview certificates.
- **Section Navigation:** Smooth scrolling with active navigation links.

## Technologies & Tools Used
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons & Fonts:** Font Awesome, Google Fonts (Orbitron & Sans-serif)
- **Version Control & Hosting:** Git, GitHub, GitHub Pages
